# Elyse Residence Reference Notes

The reference uses a luxury editorial language built from near-black charcoal surfaces, warm cream typography, high-contrast oversized serif headlines, and restrained accent color. Its composition is spacious and asymmetric, with large hero imagery, layered image tiles, small utility labels, compact pill-shaped controls, and generous negative space.

For Thoni, the transferable principles are an art-directed dark canvas, a more refined display-serif scale, compact uppercase micro-labels, a single confident accent color, layered cards or panels, and deliberate editorial pacing. The reference should not be copied literally: Thoni should retain its own messaging identity, Supabase authentication, accessibility behavior, and chat-first information architecture.

The most relevant adaptation is to make the auth screen feel like a premium editorial cover: black hero field, warm paper sign-in panel, oversized “stay close” statement, precise orange CTA, subtle framed geometry, and quiet metadata. Authenticated chat can use the same charcoal/cream hierarchy through a restrained shell, premium panel borders, and soft accent states rather than real-estate imagery.
